Contas

Usamos só as APIs públicas das plataformas. Nenhuma senha é pedida. Partidas e análises ficam salvas neste navegador (IndexedDB).

O armazenamento local não está disponível neste navegador ou modo privado. Os dados valem só até fechar a página. Use "Exportar backup" para não perdê-los.
